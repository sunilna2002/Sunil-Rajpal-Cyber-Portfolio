

### 🛡️ Security Incident Analysis (Splunk SIEM Project)

### 🔍 Objective
Analyze a high-volume dataset to detect suspicious activity and identify potential threats using SIEM (Splunk).

---

### 📊 Dataset
- Total Events Analyzed: **758,389**
- Source: Simulated enterprise security logs

---

### ⚙️ Tools & Technologies
- SIEM: Splunk  
- Query Language: SPL (Search Processing Language)  
- OS: Linux  
- Supporting: Python, SQL  

---

### 🚨 Key Findings
- Identified abnormal traffic patterns from multiple source IPs  
- Detected potential **bot-driven reconnaissance activity**  
- Highlighted high-frequency request behavior  

---

### 🧠 Investigation Approach
- Parsed logs using SPL queries  
- Filtered high-volume IP traffic  
- Correlated suspicious behavior across events  
- Ranked top offending IP addresses  

---

### 🛡️ Mitigation Recommendations
- Implement **WAF rate limiting**  
- Deploy bot detection mechanisms  
- Block or monitor suspicious IP ranges  
- Improve log monitoring thresholds
